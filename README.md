# 🤖 Basic Chatbot – Python

A simple rule-based chatbot developed using Python as part of the CodeAlpha internship task.

The chatbot interacts with the user through predefined responses based on the user's input.

## 🎯 Project Objective

To create a console-based chatbot using basic Python programming concepts.

## ✨ Features

- Responds to greetings such as `hello` and `hi`
- Responds to `how are you`
- Responds when asked for its name
- Responds to `thank you`
- Responds to `good morning`
- Responds to `good afternoon`
- Responds to `good evening`
- Handles unknown messages
- Allows continuous conversation using a loop
- Exits when the user types `bye`

## 🛠️ Technologies Used

- Python
- Functions
- While loop
- If-elif-else statements
- Strings
- User input
- Basic output

## 🚀 How to Run

1. Download `Chatbot.py` from this repository.
2. Open a terminal in the folder containing the file.
3. Run the following command:

   ```bash
   python Chatbot.py
  No external libraries or additional setup required.

## 🎮 How to Use

1. Run the Python program.
2. Enter a greeting such as `hello` or `hi`.
3. Ask `how are you`.
4. Ask `what is your name`.
5. Use `thank you` to receive a response.
6. Try `good morning`, `good afternoon`, or `good evening`.
7. Try other messages to see the chatbot's fallback response.
8. Type `bye` to end the conversation.
